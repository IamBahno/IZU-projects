## IZU - Fundamentals of Artificial Intelligence
**Author:** Bahounek Ondřej  
**Login:** `xbahou00`

This repository contains solutions to four simple assignments for the IZU (Fundamentals of Artificial Intelligence) course at FIT BUT. Each task demonstrates a basic concept or technique from the field of AI.
### 🧠 Project 1 – A* Pathfinding Algorithm

This task implements the **A\*** algorithm to find the shortest path in a map composed of regular grid cells. Each cell has a traversal cost, and impassable cells are marked as `"Z"` (wall).

### 🧠 Project 2 – Prolog: Sign Classification of List Elements

**Assignment:**  
Write a Prolog program solving the task specified by the predicate `u6(LIN, VOUT)`, where:

- `LIN` is an input list of numbers
- `VOUT` is the result variable with one of the following values:
  - `-1` if `LIN` contains only negative numbers
  - `1` if `LIN` contains only positive numbers
  - `0` otherwise (note: zero is considered neither positive nor negative)

### 🧠 Project 3 – TD-Learning in Grid World

This task applies **Temporal Difference (TD) Learning** to a 4×5 rectangular grid world. Each cell in the grid represents a state with an associated reward and estimated value. The goal is to update state values based on a predefined walk through the environment using the TD(0) algorithm.

### 🌳 Project 4 – ID3 Decision Tree

This assignment focused on implementing a decision tree classifier using the **ID3 algorithm (Iterative Dichotomiser 3)** to demonstrate how entropy and information gain are used to build classification trees.
